Every device on an IP network needs an **IP address**, a logical address that says *which network* it is on and *which host* it is within that network.

## Anatomy of an IPv4 address

An IPv4 address is **32 bits**, written as four 8-bit numbers (**octets**) in decimal: `192.168.1.130`. Each octet ranges from 0 to 255.

The address has two parts:

- **Network portion**: which network (like a street name).
- **Host portion**: which device on that network (like the house number).

The **subnet mask** says where the split is. In binary, the mask is a row of `1`s (network bits) followed by `0`s (host bits). **CIDR notation** writes it as a count of `1` bits: `255.255.255.192` = `/26`.

<Callout type="analogy">
The network part is the **street**, the host part is the **house number**. Routers only look at the street to forward mail. The final post office (the router on the destination LAN) uses the house number.
</Callout>

## How to find the network address

Line up the IP and the mask in binary and do a bitwise **AND**: wherever the mask has a `1`, keep the IP bit; wherever it has a `0`, write `0`.

- **Network address**: all host bits = 0 (can't be assigned to a host)
- **Broadcast address**: all host bits = 1 (can't be assigned; reaches every host in the subnet)
- **Usable hosts** = 2<sup>host bits</sup> − 2

<Callout type="tip" title="Shortcut: the magic number">
Find the "interesting" octet (where the mask isn't 255 or 0). **256 − that octet** = the block size. For `/26` the mask is `255.255.255.192`, so the block size is `256 − 192 = 64`. Subnets start at `.0, .64, .128, .192`. So `.130` lives in `.128 – .191`.
</Callout>

## Subnetting: making smaller networks

**Subnetting** means borrowing host bits to create more networks. Each borrowed bit **doubles** the number of subnets and **halves** the hosts per subnet.

## Private vs public addresses

Some ranges are reserved for private networks (RFC 1918). They are **not routed on the internet**. Your home router uses **NAT** to share one public IP among all of them.

| Range | CIDR | Old class |
|---|---|---|
| 10.0.0.0 – 10.255.255.255 | 10.0.0.0/8 | A |
| 172.16.0.0 – 172.31.255.255 | 172.16.0.0/12 | B |
| 192.168.0.0 – 192.168.255.255 | 192.168.0.0/16 | C |

Other special addresses: `127.0.0.0/8` (loopback, "this machine"), `169.254.0.0/16` (APIPA, link-local, which means DHCP failed), `0.0.0.0/0` (default route).

<DeepDive title="Deep dive: classful history, VLSM and the IPv4 header">

**Classful addressing** (obsolete since CIDR in 1993) fixed the mask by the first octet: Class A 1–126 (/8), B 128–191 (/16), C 192–223 (/24), D 224–239 (multicast), E 240–255 (experimental).

**VLSM** (Variable Length Subnet Masking): different subnets get different prefix sizes. Always allocate the **largest** subnet first. Example from `192.168.10.0/24`: 100 hosts → `/25` (.0), 50 hosts → `/26` (.128), 20 hosts → `/27` (.192), point-to-point links → `/30` or `/31`.

**Hosts formula**: need *h* hosts → smallest *n* where 2<sup>n</sup> − 2 ≥ h → prefix = 32 − n.

**Wildcard mask** = inverse of the mask (`0.0.0.63` for /26), used in ACLs and OSPF `network` statements.

**Summarisation**: `192.168.0.0/24` … `192.168.3.0/24` → `192.168.0.0/22` (they share the first 22 bits).

**IPv6** uses 128-bit addresses (`2001:db8::1`), no broadcast (multicast instead), no NAT needed, and a fixed 40-byte header. The standard subnet size for a LAN is `/64`.
